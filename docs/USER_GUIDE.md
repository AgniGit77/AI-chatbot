## Getting Started

### First Time Setup

1. **Open the Application**: Navigate to the chatbot URL in your web browser
2. **Optional Profile Setup**: Click the settings icon to enter your measurements for better recommendations
3. **Start Chatting**: Simply type your fashion questions in the chat box!

### Anonymous Mode

You can use the chatbot without creating an account. All features are available in anonymous mode, and your data will only be stored temporarily for the current session.

## Core Features

### 1. Virtual Try-On 👔

See how clothes look on you before buying!

**How to use:**
1. Click the camera icon or say "I want to try on clothes"
2. Upload your photo (optional - you can also create an avatar)
3. Paste the product URL from any online store
4. Click "Try It On" to see the result

**Supported stores:** Works with most major retailers including Amazon, ASOS, Zara, H&M, and more!

### 2. Fit & Size Recommendations 📏

Get accurate size recommendations based on your measurements.

**How to use:**
1. Go to Settings and enter your measurements
2. Share a product link
3. Ask "What size should I get?"
4. Receive personalized size recommendations

**Tips:**
- Enter accurate measurements for best results
- Update measurements if your size changes
- Specify your fit preference (fitted, regular, loose)

### 3. Styling Advice 🎨

Get expert styling tips and outfit suggestions.

**How to use:**
- Ask questions like:
  - "How should I style this dress?"
  - "What shoes go with these pants?"
  - "What should I wear to a wedding?"
  - "Help me create a casual outfit"

**Features:**
- Color coordination advice
- Occasion-appropriate suggestions
- Accessory recommendations
- Seasonal styling tips

### 4. Product Search & Alternatives 🔍

Find similar items or alternatives at different price points.

**How to use:**
- Say "Find me similar items"
- "Show me cheaper alternatives"
- "I'm looking for a blue dress under $100"

### 5. Outfit Builder 👗

Create complete outfit combinations.

**How to use:**
1. Share a base item (like a shirt or pants)
2. Ask for outfit suggestions
3. Save your favorite combinations
4. Access saved outfits anytime in your profile

## Troubleshooting

### Common Issues

#### Virtual Try-On Not Working

**Solutions:**
1. Ensure your photo is clear and well-lit
2. Check that the product URL is valid
3. Try a different product from a supported retailer
4. Clear your browser cache

#### Size Recommendations Inaccurate

**Solutions:**
1. Verify your measurements are correct
2. Update measurements if they've changed
3. Check that you've entered measurements in the correct units (cm/kg)
4. Note that recommendations are estimates - always check size charts

#### Can't Upload Photos

**Solutions:**
1. Check file format (JPG, PNG, GIF supported)
2. Ensure file size is under 16MB
3. Try a different photo
4. Check browser permissions for file uploads

#### Slow Performance

**Solutions:**
1. Close other browser tabs
2. Check your internet connection
3. Try a different browser
4. Clear browser cache and cookies

### Error Messages

| Error | Meaning | Solution |
|-------|---------|----------|
| "No active session" | Session expired | Refresh the page |
| "Invalid file type" | Wrong image format | Use JPG, PNG, or GIF |
| "Product URL required" | Missing URL | Paste a valid product link |
| "Failed to process" | Server error | Try again in a few moments |
